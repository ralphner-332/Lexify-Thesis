<objective>
Build the backend Post-V3 Final Evaluation Module, Configurable Survey Engine, Descriptive Statistics Service, and Multi-Format Research Export Pipeline for Phase 4:
1. Extend Prisma schema with `FinalEvaluationReview`, `SurveyQuestionnaire`, `SurveyQuestion`, and `SurveyResponse` models.
2. Seed default configurable questionnaires for Student Usability (`USAB-01`) and Expert AI Assessment Capability (`USAB-02`).
3. Post-V3 Final Review service (`FEVL-01`) allowing legal experts to inspect unblinded V3 AI outputs and submit immutable structured agreement ratings, reasoning correctness, error tags, and recommended scores.
4. Survey service supporting questionnaire CRUD, question ordering, and immutable response collection.
5. Descriptive Statistics service (`STAT-01`) calculating Mean Absolute Delta ($|\text{AI} - \text{Expert}|$) progression across V1 → V2 → V3, criterion-level deltas, and score distributions with demo filtering.
6. Multi-format research export service (`REPO-01`) generating 10 CSV datasets and a unified research JSON bundle.
7. Automated 10-point behavioral verification test suite.

Purpose: Complete the empirical research platform with post-V3 validation, usability feedback, descriptive statistical metrics, and thesis-ready data export.
Output: Working Express REST endpoints, DTO serializers, and automated verification suite for Phase 4.
</objective>

  <action>
    Extend `prisma/schema.prisma` with:
    1. `FinalEvaluationReview`:
       - `id`: String @id @default(uuid())
       - `expertId`: String
       - `expert`: User @relation(fields: [expertId], references: [id])
       - `evaluationId`: String
       - `evaluation`: Evaluation @relation(fields: [evaluationId], references: [id])
       - `sessionId`: String
       - `questionId`: String
       - `agentVersionId`: String
       - `agreementRating`: Int // 1-5
       - `reasoningCorrectnessRating`: Int // 1-5
       - `statutoryGroundingRating`: Int // 1-5
       - `recommendedScore`: Float
       - `aiScore`: Float
       - `scoreDelta`: Float // recommendedScore - aiScore
       - `errorTags`: String // JSON array: ["STATUTORY_MISINTERPRETATION", "MISSING_LEGAL_ELEMENT", etc.]
       - `qualitativeComments`: String @default("")
       - `improvementSuggestions`: String @default("")
       - `finalVerdict`: String // "ACCEPTABLE" | "ACCEPTABLE_WITH_MINOR_ISSUES" | "REQUIRES_IMPROVEMENT"
       - `questionSnapshot`: String // JSON snapshot
       - `studentAnswer`: String
       - `isDemo`: Boolean @default(true)
       - `createdAt`: DateTime @default(now())
       - Strictly NO `updatedAt` (append-only!). Unique on `(expertId, evaluationId)`.
    2. `SurveyQuestionnaire`:
       - `id`: String @id @default(uuid())
       - `title`: String
       - `description`: String
       - `targetRole`: String // "STUDENT" | "EXPERT"
       - `version`: String @default("1.0")
       - `isActive`: Boolean @default(true)
       - `isDemo`: Boolean @default(true)
       - `questions`: SurveyQuestion[]
       - `responses`: SurveyResponse[]
       - `createdAt`: DateTime @default(now())
       - `updatedAt`: DateTime @updatedAt
    3. `SurveyQuestion`:
       - `id`: String @id @default(uuid())
       - `questionnaireId`: String
       - `questionnaire`: SurveyQuestionnaire @relation(fields: [questionnaireId], references: [id], onDelete: Cascade)
       - `code`: String
       - `prompt`: String
       - `questionType`: String // "LIKERT_5" | "OPEN_TEXT" | "MULTIPLE_CHOICE"
       - `options`: String @default("[]") // JSON string
       - `orderIndex`: Int @default(0)
       - `isRequired`: Boolean @default(true)
       - `createdAt`: DateTime @default(now())
    4. `SurveyResponse`:
       - `id`: String @id @default(uuid())
       - `questionnaireId`: String
       - `questionnaire`: SurveyQuestionnaire @relation(fields: [questionnaireId], references: [id])
       - `respondentId`: String
       - `respondent`: User @relation(fields: [respondentId], references: [id])
       - `respondentRole`: String // "STUDENT" | "EXPERT"
       - `questionnaireSnapshot`: String // JSON snapshot of questions
       - `answers`: String // JSON string: { [questionId]: answerValue }
       - `qualitativeNotes`: String @default("")
       - `isDemo`: Boolean @default(true)
       - `createdAt`: DateTime @default(now())
       - Strictly NO `updatedAt` (append-only!).
    Update `User` and `Evaluation` relations.
    Push schema to database via `npx prisma db push`.

    Update `prisma/seed.ts` to seed:
    - Default Student Usability Questionnaire (6 Likert items: Diagnostic Feedback Clarity, Usefulness, Educational Value, Navigation Ease, Understanding Results, Overall UI Experience + 1 Open text).
    - Default Expert Capability Questionnaire (6 Likert items: Consistency, Legal Grounding, Scoring Accuracy, Reasoning Quality, Formative Assessment Utility, Educational Suitability + 1 Open text).
  </action>
