<objective>
Build the backend Semantic AI Evaluation Engine, Assessment Session Management, and Immutable Evaluation Persistence for Phase 2:
1. Prisma schema models for `AssessmentSession`, `StudentAnswerDraft`, and `Evaluation`.
2. Server-side draft answer persistence and session state management endpoints.
3. Semantic AI evaluation engine with Zod schema validation, multi-provider LLM support, strict anti-hallucination prompting, and fail-safe error handling (no score fabrication in research mode).
4. Immutable Evaluation persistence recording the producing Agent Version ID ("V1"), model configuration, and rubric snapshot.
5. Role-specific Evaluation DTOs delivering rich diagnostic feedback to students while strictly withholding model reference answers and grading keys.

Purpose: Deliver a rigorous, reproducible, and secure AI evaluation backend grounded in Philippine Criminal Law I reference materials.
Output: Working Express REST endpoints for student assessment sessions, submission processing, and AI evaluation retrieval.
</objective>

  <files>src/services/ai-evaluator.service.ts</files>
  <read_first>.planning/phases/02-semantic-ai-evaluation-engine-student-assessment-portal/02-CONTEXT.md</read_first>
  <action>
    Implement `src/services/ai-evaluator.service.ts`:
    - Define Zod schema `EvaluationOutputSchema` enforcing:
      - `numericalScore`: number
      - `maxScore`: number (computed from sum of criteria maxPoints)
      - `scoringBasis`: string
      - `criterionScores`: array of `{ criterionName, score, maxPoints, reasoning }`
      - `strengths`: string[]
      - `missingElements`: string[]
      - `areasForImprovement`: string[]
      - `confidenceScore`: number (0.0 to 1.0)
      - `reviewFlags`: string[]
    - `buildEvaluationPrompt(question, rubric, agentVersion, studentAnswer)`: injects system instructions, scenario, reference answer, statutory elements, provisions, concept variations, and rubric criteria with strict anti-hallucination directives (no invented rules/cases/facts).
    - `evaluateAnswer(params)`:
      - Reads `provider` and `modelId` from active `AgentVersion.modelConfig`.
      - If `GEMINI_API_KEY` is present and provider is `google`, calls Gemini API with structured JSON output.
      - If provider is unavailable or fails:
        - In research mode (`isDemo: false`), throws error to fail safely without fabricating scores.
        - In demo/simulation mode (`isDemo: true`), executes structured legal simulation clearly marked with review flag `DEMO_SIMULATION`.
  </action>
  <verify>npx tsc --noEmit</verify>
  <acceptance_criteria>
    - EvaluationOutputSchema validates all 9 required output fields.
    - buildEvaluationPrompt includes all 7 grounding components.
    - Real evaluation fails safely if LLM unreachable (no fake scores generated).
    - Simulated evaluations are explicitly tagged with DEMO_SIMULATION flag.
  </acceptance_criteria>
  <done>Semantic AI evaluation engine implemented with strict prompt grounding and Zod validation.</done>
