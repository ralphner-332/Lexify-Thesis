<objective>
Build the frontend Student Assessment Portal & AI Diagnostic Feedback UI for Phase 2:
1. Multi-step Question Wizard (`AssessmentWizard.tsx`) supporting unhardcoded question counts and server-side draft sync.
2. Pre-submission Review Screen (`ReviewAnswersPage.tsx`) displaying question completion checklist and revision navigation.
3. Post-submission Diagnostic Feedback Viewer (`FeedbackViewer.tsx`) presenting overall scores, criterion breakdowns, strengths, missing elements, and actionable advice without exposing confidential answer keys.
4. Researcher AI Evaluation Explorer (`AdminEvaluationExplorer.tsx`) for reviewing AI outputs, confidence flags, and Agent version tags.

Purpose: Deliver an intuitive, professional exam experience for law students and an educational diagnostic feedback interface tailored for Philippine Criminal Law I analysis.
Output: Integrated React components and routes for exam taking, submission, feedback viewing, and evaluation inspection.
</objective>
