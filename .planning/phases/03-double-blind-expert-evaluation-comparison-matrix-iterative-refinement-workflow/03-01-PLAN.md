<objective>
Build the backend Double-Blind Expert Evaluation Workflow, AI-vs-Expert Comparison Matrix, Structured Refinement Framework, and Agent Version Transition Engine for Phase 3:
1. Prisma schema models for `ExpertEvaluation` (append-only), `ExpertDraft`, and `RefinementLog`, plus `parentVersionId` and `changelog` fields on `AgentVersion`.
2. Double-blind expert evaluation queue with server-enforced student anonymity (`Student-01`), draft saving, and immutable submission locking.
3. Server-enforced double-blind security strictly preventing leakage of AI evaluation scores or reasoning to experts prior to expert submission.
4. AI vs. Expert comparison service calculating score deltas (`Expert Score - AI Score`), criterion deltas, reasoning comparisons, and configurable conflict detection signals.
5. Structured Refinement Log service enabling researchers to log gaps, root cause analyses, expert rationale, and approved component adjustments with 1-click comparison evidence linking.
6. Agent Version transition engine (V1 → V2 → V3) with parent version lineage, structured changelogs, diff inspection, and immutable snapshot publication.
7. Automated behavioral verification test suite.

Purpose: Deliver a rigorous, reproducible, double-blind empirical research pipeline comparing structured AI evaluations against expert legal assessments and facilitating iterative refinement.
Output: Working Express REST endpoints, DTO serializers, and automated verification suite for Phase 3.
</objective>
