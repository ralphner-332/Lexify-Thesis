<objective>
Build the frontend Double-Blind Expert Portal, AI-vs-Expert Comparison Matrix Dashboard, Structured Refinement Manager, and Version Lineage Console for Phase 3:
1. Double-Blind Expert Portal (`ExpertDashboard.tsx` & `ExpertGradingWorkspace.tsx`) with student anonymity (`Student-01`), reference materials view, criterion scoring, and draft auto-save.
2. AI vs. Expert Comparison Matrix Dashboard (`ComparisonMatrixDashboard.tsx`) with side-by-side metrics, delta calculations, reasoning comparisons, configurable conflict sliders, and 1-click refinement creation.
3. Structured Refinement Manager (`RefinementManager.tsx`) for logging, triaging, and approving Agent component modifications.
4. Version Lineage Console (`VersionLineageConsole.tsx`) displaying V1 → V2 → V3 lineage, structured changelogs, diff inspection, and version branching controls.

Purpose: Deliver an intuitive, research-grade user interface for independent legal experts and academic researchers conducting empirical AI refinement.
Output: Integrated React components, views, and routes for double-blind grading, comparison analysis, refinement logging, and version management.
</objective>
