  <action>
    Implement Role-Specific Question DTO Serializer (`src/dto/question.dto.ts`):
    - `toStudentQuestionDTO(q)`: returns ONLY `{ id, code, title, scenario, orderIndex, isActive }`. Explicitly OMIT `modelAnswer`, `statutoryElements`, `relevantProvisions`, `conceptVariations`.
    - `toAdminQuestionDTO(q)`: returns full question details including model answers, statutory elements, provisions, variations, and timestamps.
    - `toExpertQuestionDTO(q)`: returns question scenario + model answer / legal provisions for reference during evaluation, but strictly omits any AI scoring or evaluation data.

    Implement Question management endpoints in `question.controller.ts`:
    - `GET /api/questions`: enforces DTO serialization based on `req.user.role`. Students only get active sanitized questions.
    - `GET /api/questions/:id`: sanitized by role.
    - `POST /api/questions`: Admin only. Creates question, logs audit entry.
    - `PUT /api/questions/:id`: Admin only. Updates question, logs audit entry.
    - `DELETE /api/questions/:id`: Admin only. Deletes question, logs audit entry.

    Implement Rubric management endpoints in `rubric.controller.ts`:
    - `GET /api/rubrics`: lists rubrics with criteria.
    - `GET /api/rubrics/:id`: gets specific rubric.
    - `POST /api/rubrics`: Admin only. Creates rubric and criteria with validation that total weight equals 100%. Logs audit entry.
    - `PUT /api/rubrics/:id`: Admin only. Updates rubric, validates weights, logs audit entry.
    - `DELETE /api/rubrics/:id`: Admin only. Deletes rubric, logs audit entry.

    Implement Agent Version snapshot endpoints in `agent-version.controller.ts`:
    - `GET /api/agent-versions`: lists all version snapshots.
    - `GET /api/agent-versions/:id`: gets specific version snapshot.
    - `POST /api/agent-versions`: Admin only. Creates draft version with configurable modelConfig (provider, modelId, temperature, topP, maxOutputTokens), systemInstructions, skillsDefinition, evaluationPatterns.
    - `POST /api/agent-versions/:id/lock`: Admin only. Sets `isLocked: true`, `lockedAt: new Date()`. Once locked, snapshot can never be edited or deleted. Logs audit entry.
    - `POST /api/agent-versions/:id/activate`: Admin only. Sets version as active for evaluations.

    Implement Audit Log query endpoints in `audit.controller.ts`:
    - `GET /api/audit-logs`: Admin only. Read-only list of immutable audit records with filtering by entityType, userId, and date range. Strictly NO PUT/DELETE endpoints exist.

    Wire all routes into `src/app.ts` with CORS, JSON body parser, request logger, and centralized error handler.
    Create `src/server.ts` to start HTTP server on configured PORT.
